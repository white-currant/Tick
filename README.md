# Tick

Чеклисты и памятки для macOS в стиле авиационных карт (SwiftUI, macOS 14+).

- **Два типа листов**: чеклист с отметками и памятка — тезисы с командами/значениями. У каждого пункта есть текст и значение («ЗАКРЫЛКИ ........ 15»); короткое значение идёт в строку через точечный лидер, длинная команда — отдельной строкой. Внутри листа можно ставить заголовки разделов.
- **Правка** — три колонки: папки, списки с поиском, лист. ↩ новый пункт, ⌥↩ перенос строки, ⌫ на пустом удаляет, ⇥ или ↓ из текста к значению (⇧⇥ или ↑ обратно), ↓/↑ с крайних полей переходят между пунктами, пункты перетаскиваются за ручку ≡, листы — в папки.
- **Просмотр** — компактная карточка с тёмной шапкой, аварийной полосой и янтарной рамкой, поверх всех окон и на всех рабочих столах, таскается за любое место. Клик по любому месту пункта копирует его значение (или текст, если значения нет) — строка на секунду подсвечивается «СКОПИРОВАНО». Протяжка мышью по-прежнему выделяет текст; ☰ в шапке — переключение листов с поиском; листы сгруппированы по папкам, при поиске пустые папки скрываются.
- **Тема**: как в системе / светлая / тёмная — кнопка в шапке или в тулбаре, меню «Вид → Тема».
- Лист «Горячие клавиши Tick» встроенный: удалить нельзя, при отсутствии создаётся заново.
- Горячие клавиши: ⌘E режим, ⌘N чеклист, ⌘⌥N памятка, ⌘⇧N папка, ⌘F поиск, ⌘⇧C копировать лист, ⌘⇧R сбросить отметки, ⌘⌫ удалить.

## Данные

Приложение открывается в просмотре; правка — по кнопке ✎ или ⌘E.

Файл `checklists.json` лежит в `~/Library/Containers/com.yulion.tick/Data/Library/Application Support/Tick/`. Меню «Файл»:
- **Показать данные в Finder** — открыть папку с файлом.
- **Папка для данных…** — перенести хранилище в свою папку (iCloud Drive, Dropbox). Если там уже есть `checklists.json`, спросит: открыть его или заменить текущими.
- **Папка по умолчанию** — вернуться в контейнер.

Рядом с файлом папка `backups/` — по одной копии в день, хранятся последние десять.

## Сборка

```bash
xcodebuild -project Tick.xcodeproj -target Tick -configuration Release SYMROOT="$PWD/build" build
```

Готовое приложение: `build/Release/Tick.app`. Иконка: `swift Scripts/make-icon.swift Tick/Assets.xcassets/AppIcon.appiconset`.
